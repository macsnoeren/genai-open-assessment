- [ ] Externe koppeling met API-key. In een andere website wil men een toets uitvoeren met open vragen. Deze wordt dan aangeroepen en vervolgens maakt deze student de toets. De toets wordt dan automatisch nagekeken. Via een hook kan de externe website de status tracken en als de student deze inlevert, dan komt men terug op de pagina. Als het confident niet hoog scoort, dan zal in de externe website een persoon de toets nog met de hand moeten nakijken. Via de API kan er een lijst worden opgevraag van de openstaande systemen.
